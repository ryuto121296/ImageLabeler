## Project Overview

Desktop image labeling application for PC. Built with **PySide6** (Qt GUI) and **OpenCV** for image processing.

## Environment

- Python virtual environment: `.venv/`
- Activate: `.venv\Scripts\Activate.ps1` (PowerShell)

## Running the App

```powershell
.venv\Scripts\python.exe main.py
```

## Key Dependencies

- `PySide6` — main GUI framework (Qt bindings for Python)
- `opencv-python` — image loading and processing

Install dependencies after setting up the project:

```powershell
.venv\Scripts\pip install PySide6 opencv-python
```
